Answer Key and Explanations
1. B — OpenGL exposes graphics-rendering operations.
2. C — Khronos maintains the OpenGL specification.
3. B — OpenGL can be paired with platform-specific or cross-platform window toolkits.
4. C — GLUT supplies window and event-loop services.
5. B — This is the course's simplified forward pipeline order.
6. A — Vertex attributes are supplied at vertex specification.
7. B — Vertex shaders commonly transform vertex positions.
8. C — A vertex shader operates per submitted vertex.
9. A — Assembly interprets vertices according to the selected primitive mode.
10. B — The optional geometry shader works on whole primitives.
11. C — Rasterization finds the fragments covered by primitives.
12. B — A fragment is only a candidate; later tests may reject it.
13. C — The fragment shader computes per-fragment outputs.
14. A — Depth values resolve front-to-back visibility.
15. B — Blending combines incoming and stored colors.
16. A — The scissor test restricts rendering to a rectangle.
17. B — Clipping avoids processing invisible portions outside the viewing region.
18. A — Both are developer-programmable shader stages.
19. C — Accepted samples update framebuffer attachments.
20. B — Later tests mean a generated fragment may never affect the displayed image.
21. B — A centered, wide rectangle spanning x=-0.4..0.4 and y=-0.2..0.2.
22. A — A, B, then D (possibly D again later). C normally never prints because the main loop does not return.
23. B — The triangle is cleared immediately after being drawn.
24. D — Positive x is right; negative y is down.
25. B — The call registers display; GLUT invokes it when drawing is required.
